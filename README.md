# Backend E-commerce NBA

API RESTful desarrollada con Spring Boot, Spring Data JPA y MySQL para la gestión de un e-commerce enfocado en productos de la NBA. 

## Características Principales
* Arquitectura en capas (Controller, Service, Repository, Model, DTO).
* Operaciones CRUD completas para productos y usuarios.
* Manejo global de excepciones con respuestas HTTP estandarizadas.
* Persistencia relacional con MySQL mediante contenedores Docker.
